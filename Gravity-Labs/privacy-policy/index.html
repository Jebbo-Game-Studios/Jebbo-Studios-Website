Privacy Policy

Gravity Labs

This privacy policy applies to the mobile game Gravity Labs, developed and published by Jebbo Game Studios.

Information Collection and Use

Gravity Labs does not collect, store, or share any personal information or user data.

The game does not require users to create accounts, provide personal information, or connect to external services.

Third-Party Services

Gravity Labs is developed using the Unity game engine. While Unity technology is used to build and run the application, this game does not include advertising, analytics, or third-party data collection services.

Jebbo Game Studios does not collect, store, or share any user data through this application.

Children’s Privacy

Since Gravity Labs does not collect any personal data from users, it does not knowingly collect information from children or any other users.

Changes to This Privacy Policy

This privacy policy may be updated in the future if the functionality of the game changes. Any updates will be reflected on this page.
